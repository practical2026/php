Q1. Create files, configure `.gitignore`, and verify

1. Open Command Prompt and initialize a new repository:

```bat
mkdir q1-repo
cd q1-repo
git init
mkdir build

```

2. Create the required files:

```bat
echo temporary output>build\output.log
echo Local note>draft.txt

```

3. Create `.gitignore`: Open Notepad, add the following lines, and save the file as `.gitignore` (All Files) in your `q1-repo` folder.

```text
build/
*.log
.env

```

4. Verify the ignore rules and check staged changes:

```bat
git check-ignore -v build/output.log
git add .gitignore draft.txt
git diff --staged

```

### Q11. Create Declarative Pipeline `pipeline-hello`

1. In Jenkins, click **New Item**, name it `pipeline-hello`, select **Pipeline**, and click **OK**.
2. Scroll to the **Pipeline** section, ensure Definition is **Pipeline script**, and paste:

```groovy
pipeline {
    agent any
    stages {
        stage('Hello') {
            steps { echo 'First student pipeline' }
        }
        stage('Check Windows') {
            steps {
                bat 'ver'
                bat 'git --version'
            }
        }
    }
    post {
        success { echo 'All stages completed' }
        failure { echo 'Read the failing stage console' }
    }
}

```

3. Click **Save** and **Build Now**.
4. **Fail and restore:** Click **Configure**, change `bat 'ver'` to `bat 'exit /b 1'`, save, and click **Build Now**. It will fail. Click **Configure**, change it back to `bat 'ver'`, save, and build to restore.

### Q12. Write `Jenkinsfile` and push to GitHub

1. In your local `student-calculator` project directory, create a file named exactly `Jenkinsfile` (no file extension).
2. Paste the following pipeline code into it:

```groovy
pipeline {
    agent any
    tools { jdk 'JDK21'; maven 'Maven3' }
    options {
        disableConcurrentBuilds()
        timeout(time: 15, unit: 'MINUTES')
        skipDefaultCheckout(true)
    }
    parameters {
        booleanParam(name: 'RUN_APP', defaultValue: true, description: 'Run the packaged calculator')
    }
    stages {
        stage('Checkout') {
            steps {
                deleteDir()
                checkout scm
            }
        }
        stage('Verify') {
            steps { bat 'call mvn -B clean verify' }
        }
    }
}

```

3. Push to GitHub:

```bat
git add Jenkinsfile
git commit -m "Add Jenkinsfile"
git push origin main

```

### Q13. Create Pipeline `calculator-pipeline` using Pipeline script

1. Create your `student-calculator` Maven project locally and push it to a new GitHub repository.
2. In Jenkins, click **New Item**, name it `calculator-pipeline`, select **Pipeline**, and click **OK**.
3. Under **Pipeline script**, paste the following (replace `YOUR_USERNAME`):

```groovy
pipeline {
    agent any
    tools {
        jdk 'JDK21'
        maven 'Maven3'
    }
    stages {
        stage('Checkout') {
            steps { git branch: 'main', url: 'https://github.com/YOUR_USERNAME/student-calculator.git' }
        }
        stage('Compile') { steps { bat 'call mvn -B clean compile' } }
        stage('Test') { steps { bat 'call mvn -B test' } }
        stage('Package') { steps { bat 'call mvn -B package -DskipTests' } }
        stage('Run') { steps { bat 'java -jar target/student-calculator-1.0.0.jar' } }
    }
    post {
        always { junit testResults: 'target/surefire-reports/*.xml', allowEmptyResults: true }
        success { archiveArtifacts artifacts: 'target/*.jar', fingerprint: true }
    }
}

```

4. Click **Save** and **Build Now**.

### Q14. Create Pipeline job `calculator-ci` from SCM

1. *Prerequisite: Your `student-calculator` repository must be on GitHub and contain a `Jenkinsfile` with parameters and stages.*
2. In Jenkins, click **New Item**, name it `calculator-ci`, select **Pipeline**, and click **OK**.
3. Scroll down to Pipeline, change **Definition** to **Pipeline script from SCM**.
4. Set **SCM** to **Git**.
5. Enter your GitHub **Repository URL** (`[https://github.com/YOUR_USERNAME/student-calculator.git](https://github.com/YOUR_USERNAME/student-calculator.git)`).
6. Set **Branch Specifier** to `*/main` and **Script Path** to `Jenkinsfile`.
7. Click **Save** and **Build Now**.
8. After the first build, click **Build with Parameters**, uncheck `RUN_APP` (false), and build again to verify the artifact archiving while skipping the Run stage.

### Q16. Maven project, JUnit, Jenkinsfile, SCM Pipeline

1. **Create Maven Project locally:**

```bat
mkdir student-calculator
cd student-calculator
mkdir src\main\java\com\example
mkdir src\test\java\com\example
git init

```

2. Copy `pom.xml`, create `App.java`, and create `AppTest.java` (with JUnit tests) in their respective directories.
3. **Write `Jenkinsfile`:** Create a file named `Jenkinsfile` in the root folder:

```groovy
pipeline {
    agent any
    tools { jdk 'JDK21'; maven 'Maven3' }
    stages {
        stage('Checkout') { steps { checkout scm } }
        stage('Build & Test') { steps { bat 'call mvn -B clean verify' } }
    }
    post {
        always { junit testResults: 'target/surefire-reports/*.xml', allowEmptyResults: true }
        success { archiveArtifacts artifacts: 'target/*.jar', fingerprint: true }
    }
}

```

4. **Push to GitHub:** Create an empty repository on GitHub, then execute:

```bat
git add .
git commit -m "Complete project"
git remote add origin https://github.com/YOUR_USERNAME/student-calculator.git
git push -u origin main

```

5. **Jenkins SCM Pipeline:**
* In Jenkins, create **New Item** -> `q16-pipeline` -> **Pipeline**.
* Definition: **Pipeline script from SCM**.
* SCM: **Git** -> Enter your Repository URL.
* Branch: `*/main`. Script Path: `Jenkinsfile`.
* **Save** and **Build Now**.
